# Журнал старости

Облік присутності для старост груп ХНУРЕ. Розклад кожної групи автоматично підтягується з CIST.

## Як користуватися

1. Зареєструйтеся (ім’я, email, пароль) і оберіть свою групу: факультет, курс, група.
   Одну групу може зайняти лише один староста.
2. «Студенти»: додайте список групи. Можна вставити текстом або завантажити Excel/CSV;
   Telegram і телефон у тому ж рядку розпізнаються самі.
3. «Журнал»: тиждень за розкладом CIST. Клік по клітинці: був / не був. Затисніть клітинку й протягніть,
   щоб заповнити кілька одразу; Ctrl+Z скасовує. Права кнопка миші або довге натискання — поважна причина й коментар.
4. «Експорт»: Excel, HTML для друку або CSV за день, тиждень, місяць, семестр чи свій період.
5. «Налаштування»: код для заступника старости, передача старости заступнику, зміна групи
   (записи можна зберегти в акаунті й відновити пізніше).

## Як це влаштовано

- Статичний сайт (HTML, CSS, JavaScript без збирання) на GitHub Pages.
- Дані й акаунти: Firebase Realtime Database + Authentication. Доступ до журналу групи мають лише її староста
  й заступники; правила — `database.rules.json`.
- Розклад: GitHub Actions (`.github/workflows/sync.yml`) щогодини завантажує розклад зареєстрованих груп з CIST
  і записує в Firebase (`scripts/sync.mjs`). Нові групи отримують розклад протягом 10–20 хвилин.
- План і історія розробки: `docs/PLAN.md`.
